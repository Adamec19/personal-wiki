# Základy práce s Dockerem

Základy práce s Dockerem zahrnují práci s kontejnery, prohlížení logů, spouštění příkazů pomocí `exec` a používání Docker Compose. Zdrojový repozitář tato témata sdružuje do samostatného přehledu `docker-basics`. ^[how-to/README.md:18-18]

## Související témata

Na jednotlivé oblasti navazují [[Správa životního cyklu Docker kontejnerů]], [[Logování a diagnostika Docker kontejnerů]], [[Spouštění příkazů uvnitř kontejnerů]] a [[Správa více služeb pomocí Docker Compose]]. ^[how-to/README.md:18-18]

Praktickým souvisejícím postupem je [[Obnova PostgreSQL databáze v Dockeru|obnova PostgreSQL databáze ze zálohy do Docker kontejneru]], kterou repozitář uvádí společně se seedováním vývojových dat pro Strapi v5. ^[how-to/README.md:14-14]
